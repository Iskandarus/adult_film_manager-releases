# Adult Film Manager - releases

Public downloads for **Adult Film Manager**. The source code lives in a private
repository; only the built binaries are published here.

Grab the latest build from the [Releases](../../releases/latest) page.

| Platform | File | Notes |
| --- | --- | --- |
| Windows 10/11 | `AdultFilmManager-<version>-win64.zip` | Portable. Unpack and run `adult_film_manager.exe`. |
| Android | `AdultFilmManager-<version>-arm64-v8a.apk` | Almost every phone since 2017. |
| Android, unsure | `AdultFilmManager-<version>-android.apk` | Every ABI in one file. |

Releases are built and published automatically by the project's CI/CD pipeline.
